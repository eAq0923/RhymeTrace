# RhymeTrace· 《从韵书到诗歌：基于〈佩文韵府〉的历代用韵选择研究与可视化平台构建》（原型）

这是一个只用于验证产品结构的 Web 原型，不是最终数据库或正式统计结果。

## 打开方式

直接双击 `index.html` 即可在浏览器打开；不需要安装依赖，也不需要启动后端。

## 当前可演示的交互

- 按汉、唐、宋、元、明、清筛选时间轴
- 在“次数 / 占比”之间切换图表口径
- 搜索或点击四支韵脚字
- 按韵脚字过滤诗歌证据
- 点击证据卡查看原诗、韵脚、来源和核验状态
- 明确区分“已核验样例”“候选待核验”“待接入”

## 数据边界

页面内的四支字表和图表数值是为了验证界面与交互而放入的演示数据，不应作为研究结论引用。唐代《相思》卡片保留了本地 `chinese-poetry` 语料的来源说明；宋、清卡片是扩展位示例。待《佩文韵府》字头和逐句韵脚标注完成后，可以替换脚本末尾的数据数组，而不必重写页面结构。
