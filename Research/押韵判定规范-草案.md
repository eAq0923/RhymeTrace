# 押韵判定规范（草案）

> 状态：草案 v0.1（2026-10-06），供团队改定。改定后作为标注工作台（annotate.html）的配套规程，标注全程对照执行。
> 配套：标注工作台导出的 JSONL 字段说明见 10-02.md；数据实体定义见 9-21 §6。

## 0. 适用范围

- 适用于标注工作台产出的全部 JSONL 记录。
- 首批样本：唐诗 10–20 首，以近体诗为主，可含 1–2 首古体作对照（是否纳入待团队确认，见 §8）。
- 本阶段只收诗，不收词、曲、赋。

## 1. 切句与句末字

- "句"指标点（，。！？；、）分隔的分句，与工作台的自动切分一致。
- **每个分句都必须产出一条记录**，不漏句、不并句。
- 句末字 = 分句最后一个汉字（标点不计入）。
- 句末字若为异体字或生僻字：`lineFinal` 照录原字形，规范字写入备注。

## 2. 近体诗的判定

1. **偶数句**（第 2、4、6…句）：必须入韵，默认标"韵脚"。若偶句竟不押，属疑难——按实际填，备注写"偶句失韵，存疑"，不得静默放过。
2. **首句**：可入韵可不入韵，按实际判断，两种都是正常答案。（经验提示，仅作提醒不作为依据：五言首句多不入韵，七言首句多入韵。）
3. **奇数句**（除首句外）：默认"句末非韵"。若疑似特殊格式（如辘轳格、进退格），标韵脚并备注格式名。
4. 首句借邻韵（孤雁出群）：标韵脚，备注"首句借邻韵"。
5. 判定依据的优先级：**韵书归属（《佩文韵府》/平水韵）＞ 已核验数据库 ＞ 语音直觉**。直觉只能提出疑问写进备注，不能单独定论。

## 3. 古体诗的判定

- 允许换韵：按实际韵段分别成对标注，换韵处在备注注明"换韵"。
- 邻韵通押在古体中合法：语音可协即标韵脚，备注"古体通押"。
- 仄声韵照常处理：isRhyme 照实填，韵部归属留待字表接入后补。

## 4. 异读字与疑难字

- 多音字按"在这句里的实际读音"判定（示例：「见」作"出现"解读 xiàn，与作"看见"解读不同韵——具体归属以韵书核验为准，此处仅示流程）。
- 拿不准的：isRhyme 按实际倾向填，**备注必须写"存疑"+ 原因**。
- 存疑比例的预期上限约 5%：明显超过说明本规范有漏洞，先停下来讨论改规范，不要硬标。

## 5. 标注流程与质量

1. 单首标注完成后自查：句数与原文一致、偶句全部已判、无遗漏分句。
2. 双标制（如人力允许）：同一首两人独立标注，不一致处讨论定案；单标则至少"冷却一夜后复查一遍"。
3. 导出命名：`annotate-<朝代>-<作者>-<篇名>.jsonl`，提交至仓库 `annotations/` 目录（目录待规范改定后建立）。
4. 导出即视为"已核验（人工）"——导出前请确认没有 isRhyme=null 的行，除非确实存疑留白。

## 6. 字段约定（与工作台导出一致）

| 字段 | 说明 |
| --- | --- |
| poemId / title / author / era | 诗的标识与朝代 |
| lineNo / lineText / lineFinal | 句号（从 1 起）/ 句原文（无标点）/ 句末字 |
| isRhyme | true=韵脚，false=句末非韵，null=未判 |
| judgedBy | 固定为 human（判定永远由人做出） |
| source / note | 语料来源 / 疑难与依据备注 |

## 7. 判定示例（与工作台内置《相思》一致）

红豆生南国（国·句末非韵）｜春来发几枝（枝·韵脚）｜愿君多采撷（撷·句末非韵）｜此物最相思（思·韵脚）
——绝句首句不入韵、偶句入韵的典型形态。

## 8. 待团队确认

1. 首句入韵与否将来是否需要单独统计字段？（当前记在 isRhyme 里，够用；若要单独统计再加字段）
2. 古体样本是否进首批？建议进 1–2 首作对照，但会拉高判定难度。
3. 双标制是否可行？需要两人各标同样 20 首。
4. 「存疑」是否单设一个状态（而非混在备注里）？——如果存疑量将来变大，建议升级为字段。
